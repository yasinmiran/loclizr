# solid-example

A Vite and Solid app whose messages switch language in place: a Solid signal over the loclizr locale store, passed per call, plus a keyed root as the alternative.

```bash
pnpm --filter solid-example dev
pnpm --filter solid-example build
pnpm --filter solid-example test
```

Walkthrough: [Solid guide](../../apps/web/src/content/docs/guides/solid.mdx), published at `/guides/solid/`.
