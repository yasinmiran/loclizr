# vanilla-example

A Vite app with no framework: three loclizr messages rendered into the DOM, a `<select>` that switches language without a reload, and a jsdom test that proves the switch.

- `pnpm --filter vanilla-example dev`
- `pnpm --filter vanilla-example build`
- `pnpm --filter vanilla-example test`
