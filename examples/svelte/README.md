# Svelte example

A Vite and Svelte 5 app whose markup follows `setLocale`: a rune over `subscribe` and `getLocale`, a `{#key}` block, a per-call locale override, and a mount test that switches to German.

```bash
pnpm --filter svelte-example dev
pnpm --filter svelte-example build
pnpm --filter svelte-example test
```
